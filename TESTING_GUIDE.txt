## 🎯 Test Scenarios

### **Scenario 1: Setup Produk Baru (Token Listrik)**

#### **Step 1: Daftarkan Product Type**
```bash
curl -X POST "http://localhost:5008/api/product-types" \
  -H "Content-Type: application/json" \
  -d '{
    "type_code": "TOKEN",
    "type_name": "Token Listrik",
    "required_fields": ["nomor_meteran", "nominal"],
    "optional_fields": ["kode_token", "catatan"],
    "description": "Token listrik prabayar PLN"
  }'
```

**Expected Response (201):**
```json
{
  "status": "success",
  "data": {
    "id": 2,
    "type_code": "TOKEN",
    "type_name": "Token Listrik",
    "required_fields": ["nomor_meteran", "nominal"],
    "optional_fields": ["kode_token", "catatan"],
    "description": "Token listrik prabayar PLN"
  },
  "message": "Product type Token Listrik registered successfully"
}
```

---

#### **Step 2: Tambah Produk Token Listrik**
```bash
curl -X POST "http://localhost:5008/api/products" \
  -H "Content-Type: application/json" \
  -d '{
    "product_type": "TOKEN",
    "nomor_meteran": "14123456",
    "nominal": 50000,
    "kode_token": "9921-1123-4452",
    "location": "rak_b",
    "catatan": "Pelanggan VIP"
  }'
```

**Expected Response (201):**
```json
{
  "status": "success",
  "data": {
    "id": 1,
    "product_type": "TOKEN",
    "nomor_meteran": "14123456",
    "nominal": 50000,
    "kode_token": "9921-1123-4452",

}
```

### **Scenario 4: Query dengan Filter JSON Field**

#### **Filter berdasarkan Native Field:**
```bash
curl "http://localhost:5008/api/products?product_type=KARTU"
```

#### **Filter berdasarkan JSON Field:**
```bash
curl "http://localhost:5008/api/products?product_type=KARTU&harga_modal=15000"
```

#### **Filter Multiple Fields:**
```bash
curl "http://localhost:5008/api/products?product_type=TOKEN&nominal=50000&status=active"
```

**Expected Response (200) - AUTO FLATTENED:**
```json
[
  {
    "id": 1,
    "product_type": "TOKEN",
    "nomor_meteran": "14123456",
    "nominal": 50000,
    "kode_token": "9921-1123-4452",
    "location": "rak_b",
    "status": "active",
    "catatan": "Pelanggan VIP",
    "created_at": "2026-05-20 10:00:00"
  }
]
```

### **Scenario 5: Update Produk (Merge Flex Fields)**

#### **Update Native Field:**
```bash

  -H "Content-Type: application/json" \
  -d '{

    "status": "inactive"
  }'
```

#### **Update/Tambah Flex Field:**
```bash
curl -X PUT "http://localhost:5008/api/products/2" \
  -H "Content-Type: application/json" \
  -d '{
    "harga_modal": 18000,
    "supplier": "PT ABC"
  }'
```

**Expected Response (200):**
```json
{
  "status": "success",
  "message": "Product updated successfully"
}
```

### **Scenario 8: Backward Compatibility (Legacy Phone API)**

```bash

  -H "Content-Type: application/json" \
  -d '{
    "phone_number": "08123456789",
    "operator": "xl",
    "location": "counter_a"
  }'
```

**Expected Response (201):**
```json
{
  "status": "success",
  "data": {
    "id": 3,
    "phone_number": "08123456789",
    "operator": "xl",
    "location": "counter_a",
    "status": "active",
    "product_type": "KARTU",
    "exists": true
  },
  "message": "Nomor berhasil ditambahkan ke database"
}
```

## 🔍 Verifikasi Database

Untuk melihat data langsung di SQLite:

```bash
sqlite3 stok_kartu.db

# Lihat semua produk
SELECT * FROM products;

# Lihat flex_fields dalam format JSON yang rapi
SELECT id, product_type, phone_number, json_tree(flex_fields) FROM products;

# Lihat product types
SELECT * FROM product_type_config;

# Query JSON field
SELECT * FROM products WHERE json_extract(flex_fields, '$.harga_modal') = 15000;
```

## 📚 Endpoint Summary

| Method | Endpoint | Deskripsi |
|--------|----------|-----------|
| GET | `/api/product-types` | List semua product types |
| POST | `/api/product-types` | Buat product type baru |
| GET | `/api/product-types/:code` | Detail product type |
| PUT | `/api/product-types/:code` | Update product type |
| DELETE | `/api/product-types/:code` | Delete product type |
| GET | `/api/products` | List products (dengan filter) |
| POST | `/api/products` | Tambah product (dynamic fields) |
| GET | `/api/products/:id` | Detail product |
| PUT | `/api/products/:id` | Update product (merge flex) |
| DELETE | `/api/products/:id` | Delete product |
| POST | `/api/phone/add` | Legacy - Add phone |
| POST | `/api/phone/add-bulk` | Legacy - Bulk add phones |
| POST | `/api/products/check` | Legacy - Check phone |
